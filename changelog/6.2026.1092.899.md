Database upgrade to version 226, InvoiceNow (Peppol SG) improvements, and MyInvois SVDP fix. (*899*)

<!-- truncate -->

## Database

- Database upgraded to version **226**

## Updates

- **InvoiceNow (Peppol SG)**:
  - Order response records now read from the database instead of XML.
  - Added currency code support in Peppol import.
  - Updated export to use Description if Note is empty for the Note field.
  - Updated export to round up amounts to 2 decimal places.
  - Revised tax breakdown logic in Peppol export.
  - Changed "Submit" caption to "Send".

- **Clipboard Import**:
  - Disabled null check on ControlAccount.

## Bug Fixes

- **InvoiceNow (Peppol SG)**:
  - Fixed sending Aggregated Credit Note and Service Charge without UUID.

- **MyInvois (E-Invoice MY)**:
  - Fixed missing countdown for SVDP document (#7982).
