Database upgrade to version 227, Stock Reorder Qty by Location, AI Easy Scan BRN mapping, and various bug fixes. (*900*)

<!-- truncate -->

## Database

- Database upgraded to version **227**

## Updates

- **Stock**:
  - Added Reorder Qty by Location in Maintain Stock Item (#6222).
  - Stock Reorder Advise report drag and drop to Purchase Document now proportionally follows the target document item UOM (#8007).

- **AI Easy Scan (OCR)**:
  - Added auto-mapping of customer/supplier using Business Registration Number (BRN).

- **MyInvois (E-Invoice MY)**:
  - Updated E-Invoice implementation timeline to 2026-08-30.
  - Added View Template support for MyInvois transactions.
  - Individual E-Invoice (other than special cases) now only allows submission under SVDP in Batch Submit (#7993).

- **Sales / Purchase**:
  - Added Agent, Area, and Shipper fields to the Document Transfer dialog (#7965).

- **Clipboard Import**:
  - Set SpecialAccType defaults.

- **E-Commerce**:
  - Adjusted TikTok actual return shipping fee posting.
  - Adjusted Shopee fetch product.
  - Removed unused AddToCart e-commerce module.

- **General**:
  - Allow year-end closing even when SST has not been processed (#7969).

## Bug Fixes

- **Clipboard Import**:
  - Fixed access violation during validation in Supplier Credit Note Knock Off (#8012).

- **MyInvois (E-Invoice MY)**:
  - Fixed Cash Book Entry Browse Screen not showing SVDP icon (#8006).
  - Fixed Single Test validation missing SVDP.
  - Fixed tax amount incorrectly showing "must be equal to 0" error when submitting E-Invoice using tax codes SVBD, STBD, STBD5 (#7990).

- **Stock**:
  - Fixed Stock Matrix in document entry forms not checking if item code is valid before appending to detail grid (#7997).
